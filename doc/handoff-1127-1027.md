## 1. 사용자 요청 (이번 단위)

- 4차시 "나의 진로는 과학과 어떤 관련이 있을까?"만 수업에 쓴다. 나머지 정거장은 필요 없다.
- 단순 질문·빈칸이 아니라, 학생이 말한 직업에 맞춰 AI가 조금씩 도와주는 챗봇을 원한다. "어려운가?"를 물었다.

## 2. 결정과 근거

- 앱을 4차시 전용 AI 대화 도우미 **진로 디딤돌 AI**로 바꿨다. 이전 6정거장 버전은 커밋 `eb64f66`에 남김.
- AI 연결은 claude.ai Artifact의 `sample` 기능(보는 사람의 Claude 계정으로 호출)을 썼다. 설정·키·서버 없이 바로 쓸 수 있지만 **보는 사람이 Claude 계정이 있어야** 한다.
- Claude 소비자 서비스는 만 18세 미만 이용 금지(Anthropic 고객센터, 검색 2026-11-27 확인) → 학생 개별 사용 불가, **교사 화면용**으로 안내.
- 학생 기기용은 API 키 + 키를 숨기는 서버 + 미성년자 대상 지침(Anthropic "Guidelines for Organizations Serving Minors", 2026-03-16 갱신: AI임을 알림, 콘텐츠 필터링·모니터링, 연령 확인, 아동 개인정보 법령 준수 등)이 필요 → 사용자 결정 전이라 만들지 않음.
- 한국 교육부의 초등 생성형 AI 사용 기준(연령 제한, 교사 시연 등)은 검색으로 확인하지 못함(불확실). 전북교육청 자체 가이드라인 보도만 확인.
- `sample`에는 시스템 프롬프트가 없어 지시문(`assets/tutor.js`의 rules)을 맨 앞 user 턴으로 보낸다. 단계 안내는 AI 말로 꾸미지 않고 "[화면 안내]" user 턴으로 보낸다.
- 기본 설정: `modelTier: "default"`, `effort: "low"`, `cache: false`. 선생님 설정에서 "빠르게"(`quick`)로 바꿀 수 있음.
