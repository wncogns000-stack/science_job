# 진로 디딤돌 AI

6학년 2학기 과학 「4. 과학과 나의 진로」 4차시 **"나의 진로는 과학과 어떤 관련이 있을까?"**(교과서 92~93쪽, 실험관찰 58~59쪽) 수업용 대화 도우미입니다. 학생이 말한 진로에 맞춰 AI가 한 걸음씩 묻고 단계별 힌트를 주며, 정답이나 완성 문장은 대신 쓰지 않도록 지시되어 있습니다.

## 쓰는 방법

| 여는 곳 | AI | 누가 쓰나 |
| --- | --- | --- |
| claude.ai 미리보기(Artifact) | 연결됨. 화면을 연 사람의 Claude 계정 사용량으로 답함 | 교사 화면(학생의 말을 받아 적기) |
| `dist/jinro-didimdol.html` 또는 웹 주소 | 연결 안 됨(기본 모드: 단계 안내, 3단 힌트, 칸 점검 질문) | 누구나 |

Claude 소비자 서비스(claude.ai)는 만 18세 이상만 쓸 수 있어, 학생이 각자 claude.ai 링크로 AI를 쓰는 방식은 맞지 않습니다. 학생 개인 기기에서 AI를 쓰려면 Anthropic API 키와 키를 숨기는 서버가 따로 필요하고, 미성년자 대상 서비스 지침(AI임을 알림, 콘텐츠 필터링·모니터링, 개인정보 법령 준수 등)을 따라야 합니다.

## 단계 (실험관찰 칸)

1. 하고 싶은 일 (58쪽 조사해요 1)
2. 미래 과학 기술과 나의 진로에 미치는 영향 ×2 (58쪽 조사해요 2)
3. 나의 진로와 관련된 과학적 요소: 과학 지식, 과학적 탐구 과정 (58쪽 활동해요 1)
4. 진로 목표와 계획: 현재, ( )년 뒤, ( )년 뒤 (59쪽 활동해요 2)
5. 20년 뒤 나의 모습 기사 재료 (59쪽 활동해요 3, 81쪽 양식)

## 파일

```
index.html          화면 틀
assets/tutor.js     AI 지시문, 단계·칸 정의, 기본 모드 힌트와 점검 질문 (선생님이 문장을 고치는 곳)
assets/app.js       대화 화면, AI 연결(window.claude.use("sample")), 저장
assets/style.css    화면 모양
tools/build.py      한 파일 버전 dist/jinro-didimdol.html 만들기
tools/smoke-test.js 가짜 AI로 흐름 시험
tools/a11y-check.js 접근성 자동 점검
```

문장을 고친 뒤:

```bash
python3 tools/build.py
```

## 저장과 개인정보

서버가 없고, 대화와 칸 내용은 그 기기 브라우저(localStorage)에만 저장됩니다. AI 모드에서는 대화 내용이 Claude로 보내지므로 이름, 학교, 연락처 같은 개인정보는 적지 않도록 안내합니다. 학생이 바뀌면 "옮겨 쓰기 → 처음부터 다시 하기"로 지웁니다.
