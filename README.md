# 미래 직업 박람회 2045

6학년 2학기 과학 「4. 과학과 나의 진로」 수업용 웹사이트입니다. 미래 사회의 문제별 존에서 미래 직업 부스 24곳을 둘러보고, 부스마다 과학적 탐구 과정 미션을 풀어 여권에 도장을 모으며, 마지막에 나만의 미래 직업 소개 카드를 만들어 저장합니다. 로그인과 서버가 필요 없어 학생이 각자 기기로 바로 쓸 수 있습니다.

## 여는 방법

- 파일 하나: `dist/mirae-jobs-expo.html`을 브라우저로 엽니다.
- 웹 주소(GitHub Pages): 저장소를 Pages로 배포하고 `index.html`을 엽니다.
- 구글 Apps Script: `apps-script/Code.gs`의 안내대로 `index` HTML 파일에 `dist/mirae-jobs-expo.html` 내용을 붙여 넣고 웹 앱으로 배포합니다. (이 방법은 이 작업 환경에서 직접 배포해 보지 못했습니다.)

## 파일

```
index.html            화면 틀
assets/data.js        존 4개, 부스 24곳, 추천 문항, 부스 만들기 선택지 (문장을 고치는 곳)
assets/app.js         화면, 도장 미션, 여권, 추천, 카드 그리기와 저장
assets/style.css      디자인
tools/build.py        한 파일 버전 만들기
tools/smoke-test.js   동작 시험
tools/a11y-check.js   접근성 점검
apps-script/Code.gs   Apps Script 배포용
```

문장을 고친 뒤:

```bash
python3 tools/build.py
```

## 저장과 개인정보

도장, 추천 결과, 만든 부스는 학생 기기의 브라우저(localStorage)에만 저장되고 어디로도 보내지 않습니다. 카드에는 실명 대신 모둠 이름이나 별명을 쓰도록 안내합니다.

## 알아 둘 점

- 직업 정보는 초등학생 눈높이로 쉽게 쓴 것이고 통계·전망 수치는 넣지 않았습니다. "지금 있어요 / 자라나는 중 / 상상 직업"은 2026년 기준 제작자의 분류입니다.
- 기능 구성은 다른 선생님의 진로 탐구 사이트(직업·미래 기술 도감, 나의 미래 탐구)를 참고했고, 내용과 화면은 이 교과서 흐름에 맞춰 새로 만들었습니다.
