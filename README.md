# 생각 디딤돌

6학년 2학기 과학 「4. 과학과 나의 진로」 실험관찰(52~63쪽)의 빈칸 앞에서 학생이 생각을 이어 가도록 돕는 웹앱입니다. 정답을 알려 주지 않고, 빈칸마다 필요한 사고의 단계를 디딤돌 질문, 생각 도구, 3단 힌트 사다리로 나누어 제시합니다.

## 열어 보기

- 웹 주소: 저장소를 정적 호스팅(예: GitHub Pages)에 올리고 `index.html`을 엽니다.
- 파일 하나: `dist/saenggak-didimdol.html`을 브라우저로 엽니다. 서버가 필요 없습니다.
- 교사용 안내: 앱 첫 화면 맨 아래 "선생님용 안내"(주소 끝 `#guide`).

## 파일

```
index.html        앱의 틀과 교사용 안내(<template id="tpl-guide">)
assets/style.css  화면 모양
assets/data.js    과학 렌즈, 미래 기술, 장소·직업 목록
assets/s1.js~s6.js 정거장별 질문·힌트·정리 칸
assets/app.js     화면을 그리는 엔진(저장, 힌트 사다리, 옮겨 쓰기)
tools/build.py    한 파일 버전(dist/) 만들기
```

질문이나 힌트를 고치려면 `assets/s1.js`~`s6.js`의 따옴표 안 글을 바꾼 뒤 다음을 실행합니다.

```bash
python3 tools/build.py
```

## 저장과 개인정보

서버와 로그인이 없습니다. 학생이 쓴 내용은 그 기기 브라우저의 localStorage에만 저장되며, 첫 화면의 "내 생각 지우기"로 지울 수 있습니다. 외부 요청은 Google Fonts 글꼴뿐이고, 막혀도 기본 글꼴로 동작합니다.
